0.14.4 started, then handed the terminal straight back with no window and no message. This fixes that.

- Fixed the application exiting silently after the sandbox command was run. On a Wayland session it re-executed itself with the X11 backend, and that re-execution detaches the new process and discards its output, so anything that went wrong afterwards was invisible. The launcher now chooses the display backend itself, before Chromium starts, and the application stays in the foreground where its messages can be seen.
