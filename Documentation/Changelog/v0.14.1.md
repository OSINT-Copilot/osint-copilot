A fix for Linux, where the AppImage would not open unless you knew to pass a command-line switch.

- Fixed the app failing to start on a Wayland session. Electron's Wayland backend crashes as it builds its window on some systems, which is why the instructions told you to run the AppImage with `--ozone-platform=x11`. The app now detects a Wayland session, restarts itself once with the X11 backend, and carries on. Run it however you like: from a terminal, from a file manager, or from the applications menu.
- The switch is still honoured if you pass it, including `--ozone-platform=wayland` if your system runs Electron under Wayland happily. `OC_OZONE=native` keeps whatever the session offers and skips the restart.
