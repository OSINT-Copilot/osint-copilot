0.14.3 asked you to run one command and then still would not start. This fixes that.

- Fixed `LaunchProcess: failed to execvp: /home/<user>/.cache/OSINT` after running the command 0.14.3 printed. Chromium execs the sandbox helper by splitting its path on whitespace, and 0.14.3 unpacked the application into `~/.cache/OSINT Copilot/app` — so Chromium tried to run `/home/<user>/.cache/OSINT` and aborted. The application now unpacks to `~/.cache/osint-copilot/app`, which has no spaces, and refuses to use any path that does.
- The old directory, including anything made root-owned in it, is removed on the next start.
