OSINT Copilot is now open source, under the Apache License 2.0, and free to use: it no longer
asks for a licence key. The source, the install guides for every platform and the issue
tracker are at https://github.com/OSINT-Copilot/osint-copilot.

+ Changed: the application opens without a licence key, and every feature works for everyone,
  the browser extension included. The premium licensing code stays in the source but is
  switched off, and the app makes no request to a licence server. A key entered in an earlier
  version is left where it was, unread.
+ Changed: geocoding is off until you choose a service. Creating a Location or Address used to
  send it to OpenStreetMap's public Nominatim server; now nothing is sent until you enter a
  Nominatim-compatible service under Settings → OSINT Copilot → Map.
+ Changed: automatic crash reporting is gone. Crash uploads were still set up for the upstream
  Tangent project's account, which this project cannot read or delete.
+ Changed: a new application and browser-extension icon. The previous one was Tangent's.
+ Fixed the AppImage on Ubuntu 24.04 and later asking for the sandbox command again after every
  update, which also meant the app did not come back after an in-app update. A sandbox helper
  you already approved is now carried into the new version.
+ Fixed the Beta and Bleeding Edge update channels: they were offered but never published, so
  choosing one made every update check fail. Stable is now the only channel, and an older
  release can no longer replace a newer one.
+ Fixed the portable Windows build installing a second, separate copy of OSINT Copilot when it
  found an update. It now links to the download instead.
+ Fixed help pages, error messages and links that still sent people to Tangent, its author or
  its website: Getting Started, Feedback, Calling Home, the About page, and the update and error
  screens.
+ Fixed the chat's Send button looking active with no AI runtime installed, and Enter doing
  nothing without saying why.
+ Fixed the welcome tour opening scrolled past its own title.
- The Windows installer and portable files are now named the way the update feed expects, and
  the application ships its LICENSE, NOTICE and third-party notices.
- Dependencies are updated, including electron-updater, link-preview-js and Svelte.
