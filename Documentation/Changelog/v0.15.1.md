The first published open-source release. 0.15.0 was tagged but never released; everything listed
under 0.15.0 arrives with this version, together with two fixes found while testing its builds.

+ Fixed a folder or file given to OSINT Copilot when starting it being ignored by the installed
  application: `osint-copilot ~/my-case` opened nothing, and neither did a file opened with
  OSINT Copilot on Windows.
+ Fixed the chat's Send button staying enabled with no AI runtime installed when a conversation
  was already open.
