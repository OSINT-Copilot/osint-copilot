This release is about the two builds that were never tested on the systems they are for. The
Windows installer and the RPM were both run in real virtual machines this time, and what
stopped them or got in the way there is fixed.

+ Fixed the application refusing to start on a machine with no graphics card of its own --
  virtual machines, servers and containers. Chromium's GPU process could not set up its sandbox
  without a DRM render node and took the application down with it, printing only "GPU process
  isn't usable. Goodbye." The GPU process now starts without that sandbox where there is no
  render node to use, and unchanged everywhere else.
+ Fixed the window opening larger than the screen. It was always 2000 by 1200, so on a laptop it
  ran off the edge with its title bar out of reach. It now fits the screen it opens on.
+ Fixed a cancelled or revoked licence still opening the app. The refusal was remembered like
  any other answer and read back as a valid licence on the next launch, for up to a day. A
  refused licence now stays refused, and the app asks again at every start, so renewing lets
  you straight back in.
+ Fixed the in-app documentation and changelog shipping out of date: every build since 0.14.1
  carried the upstream project's release history instead of OSINT Copilot's.
+ Fixed the licence screen, the getting-started guide and three other places still calling the
  application Tangent.
