This is an OSINT Copilot release. The in-app investigation browser is replaced by a browser extension that runs in your own browser, and the graph, canvas, chat and connection forms get a long round of fixes. The Tangent base is unchanged from v0.12.10.

+ Added the **OSINT Copilot browser extension** for Chrome and the Chromium family, tested in Chrome, Brave and Helium. It pairs with the app over loopback, filing everything it sends into the investigation you pick. The app is the only thing it talks to: nothing leaves your machine.
+ Added **highlights**. Select text on a page, highlight it and write a note about it. A highlight comes back on the next visit, and text that has since been edited is matched approximately and marked as changed. Text that is gone is listed as not found, never dropped.
+ Added **page capture from the extension**: an MHTML archive, a full-page screenshot, what was on screen and a markdown reading, each with a SHA-256, landing in the investigation as an `Evidence` entity. A PDF is kept as its original bytes as well.
+ Added **quick notes and entities from a page**: send a selection as an e-mail address, wallet, domain, IP address, username or phone number. A value already in the investigation gains a source rather than a second entity.
+ Added a **Sources note** per page under `OSINTCopilot/Sources/`, holding everything sent from that page, with each highlight's full annotation in a sidecar file beside it.
+ Added **Browser extension activity** to the command palette: everything the extension has sent, with **Remove** that takes back exactly what one item added.
+ Added a **demo investigation**, Operation Northgate, under `demo/`. It is fictional, and it uses every feature: entities and sources, the graph, timeline, map, a canvas board, saved conversations, skills, enrichers, a task agent and material collected with the extension.
- Removed the **in-app investigation browser**: panes, profiles, pivots, the selector watchlist and in-app capture. Investigating now happens in your own browser, where your logins, extensions and proxy already are, and the extension sends what matters into the vault. Captures and entities already in a vault are untouched.
- Fixed each window writing to whichever vault was opened last, so a save could land in another investigation.
- Fixed page text being able to rewrite an entity note's front matter, and a path being able to move, remove or trash a whole vault.
- Fixed an entity overwriting the note of another entity that shares its label.
- Fixed a GitHub account merging into a different site's account of the same name.
- Fixed graph workspaces losing their layouts, and the open graph not following note changes; an entity added to a named workspace now stays on it.
- Fixed the entity store being emptied while it reloaded, which made an action taken at that moment fail.
- Fixed canvas cards and groups not showing their colour, a link card's thumbnail covering its text, and the picker, card controls and media players not taking the pointer.
- Fixed the connection form dropping what was typed, linking the wrong pair of entities, and running Employment, ProjectParticipant and ContractAward backwards.
- Fixed chat not following the vault's skills, both enricher palette commands, and stock task agents writing outside the folders they are allowed.
- Fixed an enricher that was switched off still sending requests.
- Fixed the app no longer watching new folders after one vanished before it was watched.
