This is an OSINT Copilot release. It adds subscription licensing and a browsing surface; the Tangent base is unchanged from v0.12.10.

+ Added **browsing panes**: a live web page opens in a pane beside your notes and the entity graph, tiled and restored with the session. Open one with `Mod+Alt+8`.
+ Added **profiles** — separate browsing identities, each with its own cookies, logins, cache and optional proxy. Profiles keep one investigation's session from reaching another's sites. They are *not* anonymity: a site can still link them by browser fingerprint, and without a proxy by IP. The pane says so, and the **Reality Check** measures what a profile is actually exposing.
+ Added **page capture**: an MHTML archive, a markdown reading of it and a SHA-256, all taken from the same moment. Capture is off by default and armed per profile; an armed profile records every page it is shown. A capture becomes an `Evidence` entity on the graph when you promote it, carrying both the live URL and the local archive as sources.
+ Added a **selector watchlist** — strings and regexes checked against every page you look at, with hits promotable to entities. Watching is independent of capture, and a selector added later can be re-run over everything already captured.
+ Added **pivots**: select a value on a page, right-click, and open the sites worth asking about it. The panes open *unloaded* — nothing is requested, and the value is not sent anywhere, until you open one. Each pane records the value and page it came from.
+ Added `browse_proposals` to the chat assistant, so it can point at pages worth reading. Those panes are unloaded too: the assistant proposes where to look without fetching anything as you.
+ Added a **Content-Security-Policy**. Rendered markdown, model output and page text can no longer execute script in the app window.
- Fixed a privilege-escalation chain in which a vault write could extend the set of binaries the app would execute.
- Fixed the integration test harness, which could not launch the app on Linux at all.
